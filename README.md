# SAGA Engine 🎮

A JSON-configured web-based learning game engine that transforms 
any educational content into a playable adventure — zero code 
required from educators.

## What is SAGA Engine?
One engine. Infinite subjects. A teacher writes a single config 
file and the engine generates a fully playable educational game.

## Three Game Modes
- 🗺️ **QuestPath** — Story map, answer to advance (History, Science)
- ⚡ **NeuronRush** — Rapid-fire timed Q&A (Revision, Recall)
- 🃏 **MirrorMatch** — Flip cards, match pairs (Vocabulary, Definitions)

## How It Works
1. Teacher writes a JSON config file
2. Config Parser validates the file
3. Message Bus broadcasts to all modules
4. Game Logic, Mechanics, Adaptive Engine run independently
5. Renderer displays the game in the browser
